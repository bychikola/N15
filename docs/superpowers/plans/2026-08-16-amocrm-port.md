# Поэтапный план переноса amoCRM → CRM N15

Дата: 2026-08-16 · Спека: `docs/superpowers/specs/2026-08-16-amocrm-port-design.md`
Каждая фаза = отдельный детальный план (writing-plans) перед реализацией. Скрины-референсы: `scrape/screens/amocrm-*.png`.

## Фаза 0: Ядро сделок (самое важное)

Как у amo: «Неразобранное», вид «Список», быстрое добавление, причины отказа, теги.

- [ ] Коллекция Applications: добавить стадию `unsorted`, поля `tags` (array), `lossReason` (text), `budget` (number), `source` (text)
- [ ] Заявки с сайта создаются со статусом `unsorted`; в канбане первая колонка «Неразобранное»
- [ ] Drag в `new` и далее — автопривязка агента (если пуст) или подсказка назначить
- [ ] «Быстрое добавление»: инпут в колонке «Неразобранное» → новая заявка (название + клиент)
- [ ] Вид «Список» заявок: таблица (клиент, объект, агент, стадия, сумма, дата) + переключение канбан/список
- [ ] При переводе в `closed`/`rejected` — модалка причины отказа (быстрый список + своё)
- [ ] Теги на карточке заявки (добавление/удаление)

## Фаза 1: Задачи

- [ ] Коллекция Tasks: title, type (call/meeting/showing/task), dueDate, done, application?, customer?, assignedTo
- [ ] Вкладка «Задачи» в CRM: to-do line (сегодня/завтра/просроченные/выполненные) + список + календарь-неделя (упрощённо)
- [ ] Создание задачи из карточки заявки и из вкладки; отметка «выполнена»
- [ ] Счётчики на дашборде: просроченные, на сегодня, на завтра, «заявок без задач»

## Фаза 2: Клиенты (списки)

- [ ] Коллекция Customers: name, phone, email, company, position, tags, agent
- [ ] Вкладка «Клиенты»: таблица с поиском/фильтром, добавление/редактирование
- [ ] Связь заявки ↔ клиент; при создании заявки — подсказка «клиент с таким телефоном уже есть» (дедуп по телефону/email)
- [ ] Карточка клиента: данные + связанные заявки, задачи, чаты

## Фаза 3: Дашборд как у amo

- [ ] Переключатели периода: сегодня/вчера/неделя/месяц и «Все/Мои»
- [ ] Виджеты: задачи (просроченные/выполненные/к выполнению), сделок без задач, новые заявки за период, суммы
- [ ] Прогноз продаж: активные заявки по стадиям × вероятность стадии (30/60/90 дней — по сроку стадии)

## Фаза 4: Аналитика

- [ ] «Анализ продаж»: воронка конверсии по стадиям за период (как `amocrm-stats.png`), средняя длительность сделки
- [ ] Отчёт по агентам: заявки/суммы/конверсия на агента
- [ ] (Опц.) Цели агентов: месячная цель по сумме + прогресс

## Фаза 5: imBox-инбокс (доработка чатов)

- [ ] Общая лента всех чатов CRM (сейчас чаты видны только в списке по заявкам)
- [ ] Фильтры: непрочитанные, по агенту, по статусу заявки
- [ ] (Отложено) интеграции Telegram/WhatsApp — только по явному запросу

## Не переносим (сознательно)

Почта (SMTP-интеграция), звонки/АТС, AI-агенты, amoМаркет, скоринг, триггеры воронки — внешние интеграции, не нужны N15 сейчас.

## Порядок и зависимости

0 → 1 → 2 → 3 → 4 → 5. Фаза 0 критична (изменяет модель заявок), остальные независимы после неё и могут меняться местами по запросу.
