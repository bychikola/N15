# Дизайн: Перенос функционала amoCRM в закрытую CRM N15

Дата: 2026-08-16 · Статус: черновик — на утверждение пользователя
Источник: анализ реального аккаунта dzagurov95.amocrm.ru (скрины в `scrape/screens/amocrm-*.png`)

## Контекст

Пользователь получил рабочий аккаунт amoCRM и хочет поэтапно перенести его функционал в закрытую CRM N15 (`/crm`). Текущая CRM уже покрывает часть: воронка заявок (7 стадий), чаты по заявкам, объекты, агенты, дашборд-метрики.

## Что есть в amoCRM (по разделам)

1. **Рабочий стол** — виджеты: просроченные/выполненные задачи, задачи к выполнению, сделок без задач, источники сделок, сделки по менеджерам, цели, использование системы, последние файлы, прогноз продаж, звонки (вх/исх), примечания, успешные сделки, обработанные беседы, NPS, сообщения, среднее время ответа. Переключатели периодов (сегодня/вчера/неделя/месяц) и «Все/Мои».
2. **Сделки** — канбан по этапам + вид «Список»; поиск и фильтр; итоги (кол-во + сумма); «Быстрое добавление» прямо в колонке; счётчики (задач на сегодня, без задач, просроченных, новых сегодня/вчера); прогноз продаж.
3. **Воронка (настройки)** — этапы: Неразобранное → Первичный контакт → Переговоры → Принимают решение → Согласование договора → Успешно реализовано / Закрыто и не реализовано. Источники сделок, скоринг, причины отказа, триггеры.
4. **Карточка сделки** — название, этап, ответственный, бюджет, теги; контакт (имя, компания, раб. тел., email раб., должность); компания; примечание.
5. **Списки** — единый реестр контактов/компаний: таблица (наименование, компания, телефон, email), поиск + фильтр, настраиваемые колонки, массовый выбор, добавление контакта.
6. **Задачи** — to-do line/list, календарь (день/неделя/месяц), фильтры, «Задачи на сегодня/завтра».
7. **imBox** — единый инбокс цифровых бесед (мессенджеры подключаются интеграциями).
8. **Аналитика** — Анализ продаж (воронка конверсии по этапам, суммы, средняя длительность сделки), Сводный отчёт, Отчёт по сотрудникам, Список событий, Звонки, Цели; прогноз продаж на 30/60/90 дней.
9. **Почта / AI-агенты / amoМаркет** — интеграции (в N15 не переносим до явного запроса).

## Что уже есть в CRM N15

- Воронка заявок: канбан, 7 стадий (new/call/showing/negotiation/deal/closed/rejected), drag-and-drop, поиск, фильтр по агентам (админ), суммы по стадиям
- Чаты по заявкам (ChatList/ChatThread, variant lk|crm), непрочитанные
- Объекты: карточки + модальная форма
- Агенты (роли), дашборд с базовыми метриками
- Заявки с сайта падают сразу в стадию `new`

## Разрывы (что переносим)

| # | Функционал amoCRM | Статус в N15 |
|---|---|---|
| 1 | «Неразобранное» — бакет для новых заявок до назначения агента | Нет (всё сразу в `new`) |
| 2 | Вид «Список» заявок (таблица) + расширенные фильтры | Только канбан |
| 3 | Ручное создание заявки/сделки из CRM («Быстрое добавление») | Нет |
| 4 | Причины отказа при закрытии сделки | Нет |
| 5 | Теги сделки | Нет |
| 6 | Задачи: создание, сроки, типы, привязка к заявке, календарь, просрочка | Нет |
| 7 | Единый реестр клиентов (контакты): ФИО/телефон/email/компания, связь с заявками | Клиенты разрознены (users + поля clientName в заявках) |
| 8 | Полный дашборд: периоды, счётчики задач, прогноз продаж, источники | Базовые метрики без периодов |
| 9 | Анализ продаж: воронка конверсии, длительность сделки, отчёт по сотрудникам | Нет |
| 10 | imBox-инбокс: единая лента всех бесед | Чаты привязаны к заявкам, общей ленты нет |
| 11 | Цели/KPI | Нет |
| 12 | Почта, звонки, AI-боты | Не переносим (внешние интеграции) |

## Архитектурные решения

- **Коллекции Payload**: добавить `tasks`, `customers` (клиенты-контакты); расширить `applications` (теги, причина отказа, источник, бюджет, стадия `unsorted`).
- **Модель «Неразобранное»**: заявка с сайта создаётся со статусом `unsorted`; агент перетаскивает её на себя → `new` и `agent` назначается автоматически (или админ назначает вручную).
- **Задачи**: `Task { title, type (call|meeting|showing|task), dueDate, done, application?, customer?, assignedTo }`; просрочка = `!done && dueDate < now`.
- **Клиенты**: `Customer { name, phones, emails, company, position, tags, createdBy, agent }`; заявка получает `customer` relation; при совпадении телефона/email — подсказка существующего клиента (упрощённый дедуп без «покупателей» amo).
- **Дашборд**: переключатель периодов + виджеты на основе tasks/applications/messages count-запросов; прогноз продаж = суммы активных стадий × вероятность (конфиг в коде, фаза аналитики).
- **Аналитика**: воронка конверсии по стадиям (переходы за период), средняя длительность сделки (createdAt → closedAt), отчёт по агентам (заявки, суммы, конверсия).
- Стиль — текущая CRM-палитра (белые карточки, #a7814e акцент), как в воронке.
- Заявки с сайта продолжают работать без изменений (guest-флоу с телефоном, чаты, ЛК).
