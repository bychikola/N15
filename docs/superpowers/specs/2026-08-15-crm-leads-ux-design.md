# Дизайн: Переработка вкладки «Заявки» в CRM

Дата: 2026-08-15 · Статус: утверждён пользователем (обе секции одобрены)
⚠️ Работа без git-коммитов до явной команды пользователя.

## Контекст

Вкладка «Заявки» (/crm/leads) использует FunnelBoard из ЛК (светлый стиль ЛК, минимальная карточка). Пользователь отметил: стиль не вписывается в CRM, мало информации, нет быстрых действий, нет фильтров/поиска. Канбан-колонки сохраняем.

**Решения пользователя:**
- Полная карточка в CRM-стиле (белая, тёмный текст)
- Поиск по клиенту/объекту + фильтр по агенту (админ) + суммы цен по стадиям
- Подход A: переработка FunnelBoard/FunnelCard (ЛК их больше не использует — безопасно)

## 1. Карточка заявки (полная, CRM-стиль)

```
┌────────────────────────────────┐
│ Квартира на набережной    ●2   │  ← объект (жирно) + бейдж непрочитанных
│ Светлана · +7 928 111-22-33    │  ← клиент; телефон — ссылка tel:
│ [ПРОСМОТР]  Обновлено: 12 авг  │  ← тип-пилюля + дата последнего действия
│ «Добрый день! Удобно в суб…»   │  ← превью последнего сообщения
├────────────────────────────────┤
│ [←] [→]   [ЧАТ]   [☎ ПОЗВОНИТЬ]│  ← нижний ряд действий
└────────────────────────────────┘
```

- Белая карточка как `crm-card` (border #e5dfd3, radius 12px), тёмный текст
- Кнопки: ←/→ стадия (видимы всегда, не только touch), «ЧАТ» → `/crm/messages/[id]`, «ПОЗВОНИТЬ» → `tel:`
- Дата последнего действия — из последнего сообщения (lastAt) или createdAt заявки
- Drag-and-drop между колонками остаётся (десктоп)
- Данные: `FunnelApplication` расширяется полями `clientPhone`, `lastActionAt`, `objectPrice` (для сумм)

## 2. Шапка воронки и колонки

- Поиск по клиенту/объекту — локальный, debounce 200 мс, мгновенно фильтрует карточки
- Фильтр агента — только у админа (как сейчас); у агента не показывается
- Колонки: заголовок стадии + счётчик заявок + **сумма цен объектов** этой стадии («5 · 38,7 млн ₽»); при поиске суммы/счётчики пересчитываются по видимым
- Клик по карточке/«ЧАТ» — переход в диалог; polling 30 сек остаётся
