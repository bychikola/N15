# Дизайн: Воронка заявок CRM (канбан-доска агента)

Дата: 2026-08-14 · Статус: утверждён пользователем (все 4 секции одобрены)

## Контекст

N15 — Next.js 16 + Payload. Уже есть: Applications (статусы new/processing/completed/cancelled, назначение агента), чат по заявкам, ЛК с LkShell-сайдбаром (роли user/agent/admin), агенты ↔ учётки (Agents.user).

Цель: ядро CRM — визуальная воронка: агент видит свои заявки по стадиям на канбан-доске, двигает их между стадиями; админ видит все воронки с фильтром по агентам.

**Решения пользователя:**
- 7 стадий: Новая → Звонок → Показ → Переговоры → Сделка → Закрыто + Отказ
- Агент видит свои, админ — все (с фильтром по агентам)
- Канбан-доска с нативным HTML5 drag-and-drop, на мобильном — кнопки ←/→
- Подход A: страница в ЛК `/lk/funnel` (не в админке)

## 1. Стадии и миграция

Поле `status` в Applications — новые значения с порядком:

| Стадия | value | Клиенту показывается |
|---|---|---|
| Новая | `new` | «Новая» |
| Звонок | `call` | «В работе у агента» |
| Показ | `showing` | «В работе у агента» |
| Переговоры | `negotiation` | «В работе у агента» |
| Сделка | `deal` | «В работе у агента» |
| Закрыто | `closed` | «Завершена» |
| Отказ | `rejected` | «Отменена» |

Клиент в ЛК видит упрощённые 4 статуса (маппинг выше), цвета не меняются.

**Миграция существующих данных:** SQL при деплое + локально: `processing` → `call`, `completed` → `closed`, `cancelled` → `rejected`, `new` → `new`.

## 2. Карточка заявки в воронке

```
┌──────────────────────────────┐
│ ●2                      ↖    │  ← бейдж непрочитанных
│ Квартира на набережной       │  ← объект, золото, ссылка на объект
│ Светлана · +7 928 111-22-33  │  ← клиент: имя + телефон
│ ПРОСМОТР · 14 АВГУСТА        │  ← тип + дата (капс, muted)
│ «Добрый день! Удобно в суб…» │  ← превью последнего сообщения
└──────────────────────────────┘
```

- Подложка charcoal, рамка золото 15%, hover — 40% + shadow-soft
- Клик по карточке → `/lk/messages/[id]` (чат заявки)
- Без объекта — «Заявка #N»
- Превью последнего сообщения из messages (как ChatList)
- На touch-устройствах (`pointer: coarse`) внизу карточки кнопки `←`/`→` — переход в соседнюю стадию (у крайних одна)

## 3. Колонки и перетаскивание

- 7 колонок в порядке стадий; заголовок колонки — капс-золото + счётчик
- Desktop: HTML5 DnD — карточки draggable, колонки-зоны приёма; при dragover колонка подсвечивается золотой пунктирной рамкой; drop → оптимистичный переезд + PATCH status; при ошибке — откат и reload
- Пустая колонка — пунктирная зона «Перетащите сюда» (видна при drag)
- Колонки скроллятся горизонтально на мобильном (ширина ~300px)
- Polling доски 30 сек (только активная вкладка) — новые заявки появляются сами
- Без библиотек: нативный DnD, touch через CSS pointer + matchMedia

## 4. Доступы и страница

- Страница `/lk/funnel`, пункт в LkShell с иконкой `view_kanban` — **только для role=agent и admin**
- `Applications.update` ужесточается: admin → всё; agent → только `{ 'agent.user': { equals: user.id } }` (where-ограничение)
- Админ: та же доска, все заявки + фильтр сверху «Все агенты · Без агента · <имя агента>…»
- Клиенты: без изменений (упрощённые статусы, чат)
